# 🎬 Movie Watchlist API

A simple REST API built with Java and Spring Boot for managing a movie watchlist.

This project was developed as Task 1 of the NV ProjectLab Backend program.

## 🚀 Features

- View all movies
- Find a movie by ID
- Add a new movie
- In-memory data storage
- Proper HTTP status codes
- RESTful API structure

## 🛠 Technologies

- Java 17
- Spring Boot
- Spring Web
- Maven
- Postman

## 📌 API Endpoints

### Get All Movies

GET /movies

Example:

http://localhost:8080/movies

Response:

```json
[
  {
    "id": 1,
    "title": "Interstellar",
    "genre": "Sci-Fi",
    "releaseYear": 2014,
    "watched": true
  }
]
```
